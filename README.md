# BYBY.fit — версия 2

Отдельная демонстрационная версия согласованного макета.

## Публикация
GitHub Pages: ветка `main`, папка `/ (root)`. Сборка не требуется.

## Локальный просмотр
`python -m http.server 8000`, затем открыть `http://localhost:8000`.

## Перенос на VPS
Загрузить файлы в каталог веб-сервера Nginx или Caddy, подключить домен и HTTPS. Эта страница статическая и не зависит от GitHub Pages.

## Статус
Курсы, цены и сертификаты — образцы для согласования. Корзина и оплата не реализованы. Фотографии и тексты можно заменить в `index.html`; оформление — в `style.css`.
